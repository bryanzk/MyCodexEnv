当前架构

1 · Host 与 runtime hooksSessionStart：命名 → session_bearing.py；UserPromptSubmit：compaction_probe.py → model_router.py → dhf_preprompt.py；PreToolUse：harness_guard.py；PostToolUse：harness_observer.py。
2 · 通用 router 与 repo adapter通用 dispatcher 先处理 opt-out，再 lazy delegate 已知仓库，最后按生命周期阶段路由显式 DHF 工作。项目路径、fixture、命令与业务边界留在 repo-specific adapter。
3 · 生命周期与专门工作流research、requirements、planning、development、validation、review、ship、handoff 八个标准阶段选择规划、TDD、QA、安全、发布、文档或确定性 helper。
4 · 耐久治理与证据harness_recover.py、harness_checkpoint.py、harness_ledger.py、harness_transition.py、harness_eval.py、schemas、状态日志和四字段验证收据让任务可恢复、可审计。
