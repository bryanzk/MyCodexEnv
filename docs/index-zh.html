从模糊请求到可验证交付。

DHF 让智能体在正确阶段获得正确、最新且获准使用的上下文，并用可核对证据完成交付。

Core Context Supply Chain

只在工作需要时提供信息

先用这条简化链路理解信息如何进入任务；需要查看完整规则和对应关系时，再进入上下文工程。

  1. Trusted Sources可信来源：从耐久且可归因的事实开始。
  2. Session Bearing会话定位：恢复阶段、所有权和下一安全任务。
  3. Just-in-time Shaping按需塑形：只加载当前阶段和风险需要的信息。
  4. Permission Decision权限裁定：把阶段、范围和授权转换为允许或阻断。
  5. Execution Feedback执行反馈：记录实际发生了什么。
  6. Checkpoint / Recovery检查点与恢复：保留可信的重新开始位置。
